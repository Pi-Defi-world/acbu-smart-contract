# Proposal: Add Frontend Tests for Proof Upload UX

## Issue

Issue #654 (W2-Z-010) reports that `frontend/zk-comply-frontend/package.json`
has development, build, lint, and preview scripts but no test script. As a
result, the proof-upload workflow has no automated regression coverage.

## Proposed Implementation

Once the frontend source tree is available in this repository:

1. Add Vitest and the required DOM/component test dependencies to the frontend
   package.
2. Add a `test` script that runs Vitest in CI-friendly mode.
3. Add component tests for the proof-upload UX, including successful upload,
   invalid input, loading state, and upload failure handling.
4. Add the frontend test command to CI so pull requests execute the tests.

## Acceptance Criteria

- `frontend/zk-comply-frontend/package.json` includes a working test script.
- Component tests cover the proof-upload success and failure paths.
- CI runs the frontend tests.
- The frontend test suite passes locally and in CI.

## Current Checkout Status

This repository revision does not contain `frontend/zk-comply-frontend`, a
frontend `package.json`, or frontend source files. Therefore, the implementation
and tests cannot be added or verified from this checkout without introducing a
new frontend application outside the scope of issue #654.

## Scope

This proposal is limited to frontend test infrastructure and proof-upload
component coverage. It does not change smart-contract logic or unrelated CI
jobs.
